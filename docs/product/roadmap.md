# Roadmap

This roadmap records outcomes, not committed dates. Refine it after product
discovery and technical decisions.

## Phase 1: Define

- [x] Validate the core user problem and primary audience.
- [x] Map the shortest useful movie-selection journey.
- [x] Define launch scope, success measures, and data constraints.
- [x] Choose and document the initial technical stack.

## Phase 2: Prove

- [x] Build the smallest end-to-end recommendation experience in deterministic
      demo mode.
- [x] Verify the live OpenAI and TMDB integrations with provider credentials.
- Test it with representative users and realistic movie data.
- Measure time to choice, completion, and recommendation confidence.

## Phase 3: Harden

- Improve accessibility, performance, resilience, privacy, and observability.
- Automate quality checks and deployment.
- Document operational ownership and incident response.

## Later possibilities

- Group preference matching.
- Personalised recommendations and watch history.
- Regional streaming availability.
- Shareable shortlists or movie-night sessions.
